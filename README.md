# ARRAY
# Array DSA Practice

This repository contains my journey of learning and practicing **Data Structures and Algorithms (DSA) using Arrays in C++**. It is designed to build a strong foundation in array concepts and gradually improve problem-solving and algorithmic thinking.

The repository starts with **basic array operations**, including array declaration, input/output, traversal, finding maximum and minimum elements, calculating sum and average, counting positive/negative/even/odd elements, and searching for elements.

As the difficulty increases, the repository covers important problems such as **reversing an array, checking whether an array is sorted, finding first and last occurrences, finding the second largest and second smallest elements, removing duplicates, counting frequencies, moving zeroes, and finding missing or duplicate elements**.

It also includes important DSA techniques such as **Two Pointer, Sliding Window, and Kadane’s Algorithm**. Advanced problems include **array rotation, Two Sum, Majority Element, Leaders in an Array, Maximum Subarray Sum, Maximum Product Subarray, Merge Sorted Arrays, Trapping Rain Water, and other interview-oriented problems**.

Each solution is implemented in **C++**, with an emphasis on writing clean and understandable code. Wherever possible, solutions focus on improving **time and space complexity** and understanding the difference between brute-force and optimized approaches.

The purpose of this repository is not only to collect solutions but also to **track my DSA learning progress**, strengthen my programming fundamentals, and prepare for coding interviews and competitive programming.

This repository will be continuously updated as I learn new concepts and solve more challenging problems.

**Learning → Practicing → Optimizing → Improving → Mastering DSA 🚀**
